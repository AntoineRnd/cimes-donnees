# Cimes · données géographiques

Base des **cimes** (sommets, cols, collines, belvédères nommés) utilisée par le jeu Cimes, extraite d'OpenStreetMap.

- Données © les contributeurs d'OpenStreetMap, sous licence **ODbL 1.0** : https://www.openstreetmap.org/copyright
- Extraction : onglet **Actions** → « Extraction des cimes (OpenStreetMap) » → **Run workflow**.
- Source : extraits régionaux de Geofabrik (le gros fichier `.osm.pbf` n'est jamais enregistré ici).
- Résultat : `data/<région>/cimes.json` (identifiant OSM, nom, catégorie, coordonnées, altitude si connue).

Ce dépôt ne contient **que du code et des données publiques**. Aucun tracé GPS ni aucune donnée personnelle.
